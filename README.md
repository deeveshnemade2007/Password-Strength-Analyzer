# 🔐 Password Strength Analyzer

## 📌 Overview
Password Strength Analyzer is a Python-based cybersecurity project that evaluates password strength based on common security criteria. It helps users understand whether their passwords are weak, moderate, or strong.

## ✨ Features
- Checks password length.
- Identifies uppercase and lowercase letters.
- Checks for numbers and special characters.
- Evaluates overall password strength.
- Provides feedback to help create stronger passwords.

## 🛠️ Technologies Used
- **Language:** Python
- **Concepts:** Password Security, Input Validation, Cybersecurity

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/deeveshnemade2007/Password-Strength-Analyzer.git
   ```

2. Open the project folder:
   ```bash
   cd Password-Strength-Analyzer
   ```

3. Run the Python script:
   ```bash
   python "Task 1.py"
   ```

   If your Python file has a different name, replace `Task 1.py` with the correct filename.

To understand password security and learn how to identify weak passwords using Python.
